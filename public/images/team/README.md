# Team photos

Drop portraits here, then wire them up in `public/team.html`:

1. Name the file after the person or role, e.g. `founder.jpg`.
2. Crop to a **4:5 portrait** ratio (e.g. 800 × 1000). The card crops with
   `object-fit: cover`, so faces stay centred.
3. In that member's `.member-photo` block, delete the `.initials` and
   `.ph-note` divs and uncomment the `<img>` line above them.

Keep files under ~300 KB each — use JPEG or WebP.
